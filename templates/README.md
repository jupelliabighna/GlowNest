# GlowNest — Salon & Wellness Appointment Website

GlowNest is a full-stack salon and wellness appointment management
website built with Python and Flask.

## 🌐 Live Demo

https://glownest-l9ro.onrender.com

## ✨ Features

- Responsive salon and wellness website
- Service listings
- Online appointment booking
- Form validation
- Admin authentication
- Admin dashboard
- Appointment management
- Service management
- Appointment status updates
- CSRF protection
- Password hashing
- Search and filtering
- Flash messages

## 🛠️ Technologies

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- Flask-WTF
- SQLite
- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Render
